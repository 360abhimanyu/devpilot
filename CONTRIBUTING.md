# Contributing to DevPilot AI

Thanks for helping improve DevPilot!

## Before you start
- Check existing issues and pull requests.
- For a substantial feature, open an issue to discuss the design.
- Keep changes focused and explain the user problem they solve.

## Development
1. Fork and clone the repository.
2. Create a branch: `git checkout -b feat/short-description`.
3. Create a virtual environment and install `requirements.txt`.
4. Run the app with `uvicorn app.main:app --reload`.
5. Run tests with `pip install pytest && pytest -q`.

## Pull requests
Include a clear summary, screenshots for UI changes, testing steps, and any configuration changes. Never commit `.env`, API keys, or private data.

## Code of conduct
Be respectful, constructive, inclusive, and welcoming to contributors of all experience levels.
